# Nithya Residency - Hotel Management System

A professional, full-stack hotel booking and management system.

## Features
- **Multi-language Support**: English, Tamil, and Hindi.
- **Booking Management**: Complete guest registration and data tracking.
- **Admin Dashboard**: Secure owner access (password: 1234) for managing gallery images, payment QR codes, and guest data.
- **Dynamic Gallery**: Upload and manage property photos.
- **Payment Integration**: Dynamic GPay QR code for easy customer payments.
- **Data Export**: Export all booking data to Excel.

## Tech Stack
- **Frontend**: React, Framer Motion, Lucide Icons.
- **Backend**: Node.js, Express, SQLite3.
- **Styling**: Premium CSS with glassmorphism and floating animations.

## Setup
1. `cd client && npm install`
2. `cd server && npm install`
3. Start server: `cd server && node index.js`
4. Start client: `cd client && npm run dev`
